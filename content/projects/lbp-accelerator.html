Hardware-Accelerated LBP Facial Recognition System

Undergraduate VLSI design project
  • Verilog
  • RTL
  • VLSI

Local Binary Patterns recognize a face by its texture. Within a recognition architecture provided by the course, I implemented the CLBP, HCU, DCU, comparator and controller modules in Verilog and integrated them at the top level.

How it works

CLBP computes a texture code for each pixel, HCU builds histograms of those codes, DCU measures the distance to each stored reference histogram, and the comparator picks the closest. A mode signal switches between training and prediction.

Design notes

The intermediate sum is accumulated in a register so that RAM is not read repeatedly; I did not measure how much this saved. The critical path was in the HCU.

Results

Synthesized in Synopsys Design Compiler on a 16 nm FinFET library, the reported synthesis snapshot met a 2.0 ns clock target with +0.34 ns of slack, at a total cell area of 9,791 µm². The design passed Synopsys VCS SDF gate-level simulation at 500 MHz, with 82.4% Superlint coverage.

Caveats

These numbers come from a reported synthesis snapshot, not from a sign-off of the full system. A 2.0 ns clock is a 500 MHz target, but each image takes many cycles, so image throughput would need its own cycle count.

Projects

MX Precision Lab: Error-Budgeted MXFP4 Accumulator Generator
ISSCC 2027 Code-a-Chip · GF180MCU 180 nm · Fall 2026
code / submission (PR #215, merged)

A generator that takes a linear layer and an accumulation-error budget and picks the smallest GF180 dot-product core that meets it; across 14 workloads a fixed F4 accumulator misses the budget in 29 of 84 workload × budget cells and over-provisions in 32. The pipelined SystemVerilog accumulator was verified over all 129,038 RNE cases with 0 mismatches, and a C++17 cycle-accurate model matched the RTL over 64 configurations. Seven candidates were placed and routed in Yosys and LibreLane/OpenROAD with 0 DRC/LVS errors; the F2 core cut cell area 14.2% against F24.

AXI4 CDC Bridge and UVM Verification
SystemVerilog, UVM, SVA · Xcelium, Quartus, Verilator, Questa · Fall 2026
code

A block-RAM asynchronous FIFO for FPGAs: on Arria 10 a 74-bit × 16 FIFO used 22 instead of 501 ALMs and its Fmax rose from 396 to 605 MHz. A UVM environment with 85 SVA checks and functional coverage passed 269/269 Xcelium runs, covered 146/146 bins and caught 5/5 injected faults. The Arria 10 post-fit netlist matched the RTL in 11/11 tests with CDC timing met in 4 corners.

Image Convolution Engine and Pipelined Exponential Unit on FPGA
ECE1756, Prof. Vaughn Betz · Intel Agilex 7 · Fall 2026

A streaming 3×3 convolution engine (1 pixel per cycle, M20K line buffers, back-pressure) iterated through 11 versions from 12.5 to 72.9 TOPS full-device, with 4,510 copies running at the 958.77 MHz DSP limit. At an estimated 546 GOPS/W that is 126× the throughput and 208× the efficiency of the course-provided RTX 3070 baseline. In the first assignment I pipelined a Horner exponential unit to 18 stages, raising Fmax from 64.46 to 853.97 MHz.

LBP Accelerator and 32-bit RISC-V CPU
Introduction to VLSI CAD, NCKU · TSMC 16 nm · Spring 2024
details / CPU code

A Verilog accelerator for Local Binary Pattern feature extraction, with SRAM access reduced by sequential register accumulation: DC synthesis on 16 nm at 500 MHz (0.34 ns slack, 9,791 µm²), VCS gate-level simulation passed, 82.4% Superlint coverage. A single-cycle 32-bit RISC-V CPU with a custom ALU, branch logic and load filter, verified in ModelSim.

LogicMin: Boolean Logic Minimization and Verification
C++17 · exact Quine–McCluskey with branch-and-bound covering · NCKU · Spring 2023
code

An exact two-level minimizer for single-output functions with don’t-cares: Quine–McCluskey prime implicants, then an exact branch-and-bound cover. Every output is re-checked against the specification and minimality is cross-checked against a brute-force reference; 31 tests (about 103,000 checks) run in CI on Linux and macOS. Rebuilt from a NCKU logic-design assignment.

Open Source

PULP AXI: fix a W-channel deadlock in axi_burst_unwrap
pulp-platform/axi issue #448 · PR #455, merged 11 Nov 2026 · SystemVerilog
pull request

The module allocated its write counters only after the downstream AW handshake, so a slave that holds AWREADY until it sees WVALID hangs forever; the fix allocates when the transaction is first presented. Validated with a local 9-test testbench on Verilator and Questa, 3 of which hung before the fix.

Google XLS: error instead of silently overriding an explicit codegen version
google/xls issue #4554 · PR #5163, merged 27 Oct 2026 · C++
pull request

Codegen silently switched packages with proc-scoped channels to version 1.5 even when the user asked for 1.0 or 2.0. It now returns an explicit error instead, with 7 regression tests.

Project-MONAI: checkpoints that stopped loading under weights_only=True
Project-MONAI issue #9025 · MONAI PR #9143 and model-zoo PR #791, both merged · Python · Oct 2026
MONAI pull request / model-zoo pull request

Two DiNTS segmentation bundles stored their architecture-search results as NumPy arrays, which PyTorch 2.6’s safe loader refuses. MONAI’s topology decoding now accepts both tensors and lists, and the bundles save tensors, so the models load again under torch.load(weights_only=True).
